# multiplexer

## Описание

Мультиплексор 10→1, построенный на основе четырёх мультиплексоров 4→1.

Мультиплексор имеет:

- 10 информационных входов: D0–D9;
- 4 адресных входа: A3–A0;
- 1 выход: OUT.

Адресные входы A3–A0 определяют, какой из информационных входов D0–D9 будет передан на выход.

### Структура мультиплексора

| Мультиплексор | Информационные входы | Адресные входы | Выход |
|---|---|---|---|
| MUX 1 | D0, D1, D2, D3 | A1, A0 | X0 |
| MUX 2 | D4, D5, D6, D7 | A1, A0 | X1 |
| MUX 3 | D8, D9, 0, 0 | A1, A0 | X2 |
| MUX 4 | X0, X1, X2, 0 | A3, A2 | OUT |

Значение `0` означает постоянный логический ноль.

Для проверки используются следующие значения информационных входов:

- D0 = 0
- D1 = 1
- D2 = 0
- D3 = 1
- D4 = 0
- D5 = 1
- D6 = 0
- D7 = 1
- D8 = 0
- D9 = 1

Адресные входы определяют выбранный информационный вход:

| Адрес A3 A2 A1 A0 | Выбранный вход |
|---|---|
| 0000 | D0 |
| 0001 | D1 |
| 0010 | D2 |
| 0011 | D3 |
| 0100 | D4 |
| 0101 | D5 |
| 0110 | D6 |
| 0111 | D7 |
| 1000 | D8 |
| 1001 | D9 |

Адреса `1010–1111` являются недопустимыми, так как информационных входов D10–D15 не существует.

## Программная реализация

Для дополнительной проверки разработана программная модель мультиплексора на Python.

Основной файл:

multiplexer.py

В программе реализован класс Mux10.

Он выполняет следующие проверки:

количество информационных входов должно быть равно 10;
значения информационных входов должны быть 0 или 1;
адресные входы должны содержать только 0 или 1;
адреса 1010–1111 являются недопустимыми.


Автоматическое тестирование

Для автоматического тестирования используется библиотека pytest.

Запуск тестов:

python -m pytest

В проекте используются два тестовых файла:

test_mux.py
test_fault.py

test_mux.py

Проверяются:

выбор всех 10 информационных входов;
недопустимые адреса;
неправильное количество информационных входов;
недопустимые значения информационных входов;
недопустимые значения адресных входов.
test_fault.py

Проверяются модели неисправностей:

выход stuck-at-0;
выход stuck-at-1;
инверсия выходного сигнала;
A0 stuck-at-0;
D5 stuck-at-0;
неправильный выбор информационного входа.

Моделирование неисправностей

Для моделирования неисправностей используется отдельный файл:

faults.py

Неисправности моделируются отдельно от основного класса Mux10.

Неисправность	Описание
Stuck-at-0	Выход постоянно равен 0
Stuck-at-1	Выход постоянно равен 1
Инверсия	Выходной сигнал инвертируется
A0 stuck-at-0	Адресный вход A0 постоянно равен 0
D5 stuck-at-0	Информационный вход D5 постоянно равен 0
Wrong input	Выбирается неправильный информационный вход
