# multiplexer

[https://circuitverse.org/users/467194/projects/untitle-c1834be5-9dbc-4834-96ba-9b0fc6dbcbb3]
Описание

Мультиплексор 10→1, построенный на основе четырёх мультиплексоров 4→1.

Мультиплексор имеет:

10 информационных входов: D0–D9;
4 адресных входа: A3–A0;
1 выход: OUT.

Адресные входы A3–A0 определяют, какой из информационных входов D0–D9 будет передан на выход.


| **Мультиплексор** | **Информационные входы** | **Адресные входы** | **Выход** |
|---|---|---|---|
| MUX 1 | D0, D1, D2, D3 | A1, A0 | X0 |
| MUX 2 | D4, D5, D6, D7 | A1, A0 | X1 |
| MUX 3 | D8, D9, 0, 0 | A1, A0 | X2 |
| MUX 4 | X0, X1, X2, 0 | A3, A2 | OUT |

(Значение 0 означает постоянный логический ноль.)
